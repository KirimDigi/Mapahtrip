# MapahTrip (Mapahtrip.id) ⛩️ 🌸

> **Platform Bantuan Pengurusan Visa Jepang & Sistem Tracking Paspor Real-Time**  
> Standar Konsulat Jenderal Jepang & JVAC (Japan Visa Application Center).

---

## 🌟 Fitur Utama

- **Landing Page Eksklusif (Customer Portal):**
  - Katalog 8 jenis Visa Jepang (Tourist Single, Multiple, e-Visa/Waiver, Bisnis, Pelajar, Transit, Spouse/Dependent).
  - Alur 4 langkah mudah pengajuan tanpa antre.
  - Pengecekan status paspor / tracking real-time (terkoneksi database Supabase).
  - Mode Tampilan Terang & Gelap (*Light & Dark Mode Switcher*).
  - Call-to-action konsultasi langsung ke WhatsApp Official.
- **Portal Admin Operasional:**
  - Manajemen data pemohon visa (*live Supabase cloud*).
  - Rekapitulasi keuangan, margin fee, dan komisi referral.
  - Akses rahasia via URL: `#admin`.

---

## 🚀 Cara Menjalankan di Komputer Lokal

### 1. Instal Dependensi
```bash
npm install
```

### 2. Jalankan Dev Server
```bash
npm run dev
```
Buka browser di `http://localhost:5173`.

### 3. Build untuk Produksi
```bash
npm run build
```

---

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Vanilla Modern CSS (Bespoke Glassmorphism, Theme Variables)
- **Database & Backend:** Supabase Cloud Database
- **Icons & Typography:** Google Fonts (Plus Jakarta Sans, Source Serif 4, Material Symbols)
